    \subsection{NLI-Based Semantic Evaluation}
    \label{sec:nli_methodology}

    Beyond lexical overlap metrics (F1, Exact Match, BLEU, chrF) and embedding-based similarity (SBERT), we propose evaluating the semantic consistency between source and backtranslated answers through Natural Language Inference (NLI). This approach frames answer comparison as a textual entailment task: given a source answer $a_s$ and a backtranslated answer $a_{bt}$, we classify their semantic relationship.

    \subsubsection{Problem Formulation}

    For each question-answer pair generated by the AskQE pipeline, we obtain:
    \begin{itemize}
        \item $a_s$: the answer derived from the source sentence
        \item $a_{bt}$: the answer derived from the backtranslated MT output
    \end{itemize}

    We model the semantic relationship between these answers as a three-class classification problem:
    \begin{equation}
        f(a_s, a_{bt}) \rightarrow \{E, N, C\}
    \end{equation}
    where $E$ denotes \textsc{Entailment} (semantically equivalent), $N$ denotes \textsc{Neutral} (partial or uncertain overlap), and $C$ denotes \textsc{Contradiction} (semantic conflict).

    The core hypothesis is that a high-quality translation should preserve the semantic content of the source, leading to entailment between $a_s$ and $a_{bt}$. Conversely, translation errors should manifest as contradictions or neutral relationships.

    \subsubsection{Classification Approaches}

    We implement two complementary approaches to perform this classification:

    \paragraph{NLI Classifier (Baseline)}
    We employ BART-large fine-tuned on the MultiNLI corpus~\cite{williams2018multinli} (\texttt{facebook/bart-large-mnli}), a standard model for NLI tasks. Given the concatenated input $[a_s; a_{bt}]$, the model outputs logits $\mathbf{z} \in \mathbb{R}^3$ which are converted to a probability distribution via the softmax function:
    \begin{equation}
        P_{\text{NLI}}(y = c \mid a_s, a_{bt}) = \frac{\exp(z_c)}{\sum_{j \in \{E, N, C\}} \exp(z_j)}
    \end{equation}
    where $c \in \{E, N, C\}$ and $z_c$ is the logit corresponding to class $c$. The predicted label is:
    \begin{equation}
        \hat{y}_{\text{NLI}} = \arg\max_{c} \, P_{\text{NLI}}(y = c \mid a_s, a_{bt})
    \end{equation}

    This model serves as our reference classifier, since it was explicitly trained for NLI tasks.

    \paragraph{LLM-as-Judge (First-Token Probability)}
    As an alternative, inspired by recent work on using LLMs as NLI judges~\cite{chen2024seeing}, we employ a generative LLM (Qwen-2.5 3B Instruct) and extract classification probabilities via the \textit{first-token probability} method.

    The NLI task is formulated as a constrained generation problem. Given a structured prompt $\mathbf{p}$ containing both answers and the classification instruction, the prompt ends with the cue \texttt{``Label:''} to constrain the model's next-token prediction to one of three labels.

    Let $\mathcal{V}$ be the vocabulary of the LLM and let $t_E, t_N, t_C \in \mathcal{V}$ be the token IDs corresponding to the labels \textsc{Entailment}, \textsc{Neutral}, and \textsc{Contradiction}. Given the full input sequence $\mathbf{x} = [x_1, \ldots, x_T]$ (where $T$ is the length of the tokenized prompt), the model produces a logit vector over the entire vocabulary for the next token:
    \begin{equation}
        \mathbf{z}_{T+1} = f_{\theta}(\mathbf{x})_{T+1} \in \mathbb{R}^{|\mathcal{V}|}
    \end{equation}

    From this full vocabulary distribution, we extract only the logits corresponding to our three target labels:
    \begin{equation}
        \hat{\mathbf{z}} = [z_{t_E}, \; z_{t_N}, \; z_{t_C}] \in \mathbb{R}^{3}
    \end{equation}

    We then apply softmax \textit{restricted to these three logits} to obtain a probability distribution over the NLI labels:
    \begin{equation}
        P_{\text{LLM}}(y = c \mid a_s, a_{bt}) = \frac{\exp(\hat{z}_{t_c})}{\exp(\hat{z}_{t_E}) + \exp(\hat{z}_{t_N}) + \exp(\hat{z}_{t_C})}
        \label{eq:first_token}
    \end{equation}

    The predicted label is:
    \begin{equation}
        \hat{y}_{\text{LLM}} = \arg\max_{c \in \{E, N, C\}} \, P_{\text{LLM}}(y = c \mid a_s, a_{bt})
    \end{equation}

    This approach, known as \textit{first-token probability}~\cite{chen2024seeing}, offers several advantages over full generation: (i)~it requires a single forward pass rather than autoregressive decoding, making it computationally efficient; (ii)~it produces well-calibrated probability estimates through the restricted softmax; and (iii)~it eliminates the need for output parsing, since the classification is determined entirely from the logit values.

    \subsubsection{Prompt Design}

    The LLM-Judge prompt is structured as follows:

    \begin{quote}
    \small
    \texttt{You are a judge evaluating the relationship between two answers to the same question.}\\[3pt]
    \texttt{Answer A (Source): \{$a_s$\}}\\
    \texttt{Answer B (Backtranslation): \{$a_{bt}$\}}\\[3pt]
    \texttt{Classify the relationship as one of:}\\
    \texttt{- ENTAILMENT: Answer B supports or is consistent with Answer A}\\
    \texttt{- NEUTRAL: Answer B is neither clearly supportive nor contradictory}\\
    \texttt{- CONTRADICTION: Answer B contradicts or is inconsistent with Answer A}\\[3pt]
    \texttt{Respond with ONLY the label: ENTAILMENT, NEUTRAL, or CONTRADICTION.}\\
    \texttt{Label:}
    \end{quote}

    The trailing \texttt{``Label:''} cue is critical: it constrains the model's generation space and ensures that the first predicted token corresponds directly to one of the three NLI labels, enabling the first-token probability extraction described in Equation~\ref{eq:first_token}.

    \subsubsection{Aggregation Strategy}

    For each sentence $s_i$ with $n_i$ question-answer pairs, we compute the distribution of predicted labels:
    \begin{equation}
        \pi_c^{(i)} = \frac{1}{n_i} \sum_{j=1}^{n_i} \mathbb{1}[\hat{y}_j = c]
    \end{equation}
    where $\pi_c^{(i)}$ represents the proportion of questions classified as class $c$ for sentence $i$. A translation with high $\pi_E$ (entailment proportion) suggests semantic preservation, while high $\pi_C$ (contradiction proportion) indicates potential translation errors.

    \subsubsection{Confidence Estimation}

    We also track the confidence of each prediction as the probability assigned to the predicted label:
    \begin{equation}
        \text{conf}(\hat{y}) = P(y = \hat{y} \mid a_s, a_{bt})
    \end{equation}

    This allows us to analyze not only \textit{what} label is predicted, but \textit{how certain} the model is about its prediction. We hypothesize that when both the NLI classifier and the LLM-Judge agree on a label, the confidence of both models should increase, providing a natural signal for prediction reliability.

    \subsection{Inter-Model Agreement Analysis}
    \label{sec:nli_results}

    We evaluate the NLI-based metrics on the BioMQM dataset across five language pairs: German (de), Spanish (es), French (fr), Russian (ru), and Chinese (zh-CN). For each language, we process all sentence-level QA pairs through both the NLI classifier and LLM-Judge, comparing their predictions.

    \subsubsection{Overall Agreement}

    Table~\ref{tab:confusion_matrix} presents the confusion matrix between the two classification approaches across all 23,449 question-answer pairs.

    \begin{table}[htbp]
    \centering
    \caption{Confusion Matrix: LLM-Judge vs NLI Classifier}
    \label{tab:confusion_matrix}
    \begin{tabular}{l|ccc|c}
    \hline
    & \multicolumn{3}{c|}{\textbf{NLI Classifier}} & \\
    \textbf{LLM-Judge} & ENT & NEU & CON & \textbf{Total} \\
    \hline
    ENTAILMENT & 9,566 & 539 & 62 & 10,167 \\
    NEUTRAL & 3,161 & 5,079 & 525 & 8,765 \\
    CONTRADICTION & 416 & 2,385 & 1,716 & 4,517 \\
    \hline
    \textbf{Total} & 13,143 & 8,003 & 2,303 & 23,449 \\
    \hline
    \end{tabular}
    \end{table}

    The overall agreement rate is \textbf{69.77\%} (16,361 out of 23,449 predictions). This moderate agreement suggests that while both approaches capture similar semantic relationships, they exhibit systematic differences in their classification behavior.

    \subsubsection{Distribution Bias}

    We observe distinct distributional biases between the two models:

    \begin{itemize}
        \item \textbf{NLI Classifier} tends toward \textsc{Entailment}: 56.0\% of predictions vs. 43.4\% for LLM-Judge
        \item \textbf{LLM-Judge} assigns more \textsc{Contradiction}: 19.3\% vs. 9.8\% for NLI
        \item \textsc{Neutral} predictions are comparable: 37.4\% (LLM) vs. 34.1\% (NLI)
    \end{itemize}

    This asymmetry can be explained by examining the two approaches. The NLI classifier, trained on the MultiNLI dataset, was exposed to a curated distribution where entailment pairs are well-represented. The LLM-Judge, relying on pretrained language understanding and the first-token probability method, appears to apply a stricter criterion for semantic equivalence: when two answers differ even slightly, the model's logit for \textsc{Contradiction} gains more weight relative to the NLI classifier's softmax output.

    German exhibits the highest agreement (74.41\%), possibly due to its structural similarity to English, on which both models were primarily trained. Russian shows the lowest agreement (66.30\%), suggesting that morphologically rich languages with different writing systems pose greater challenges for cross-model consistency.

    \subsubsection{Confidence Analysis}

    A key finding emerges when analyzing prediction confidence. Table~\ref{tab:confidence} compares the average probability assigned to each label under two conditions: (1) when a model independently assigns that label, and (2) when both models agree on the same label.

    \begin{table}[htbp]
    \centering
    \caption{Average Confidence: Independent vs. Agreement}
    \label{tab:confidence}
    \begin{tabular}{l|cc|cc}
    \hline
    & \multicolumn{2}{c|}{\textbf{Independent}} & \multicolumn{2}{c}{\textbf{When Agree}} \\
    \textbf{Label} & LLM & NLI & LLM & NLI \\
    \hline
    ENTAILMENT & 96.66\% & 90.91\% & 96.98\% & 92.59\% \\
    NEUTRAL & 89.29\% & 88.07\% & 90.11\% & 90.91\% \\
    CONTRADICTION & 87.57\% & 81.15\% & 92.40\% & 83.07\% \\
    \hline
    \end{tabular}
    \end{table}

    We observe a consistent increase in confidence when both models agree, most notably for \textsc{Contradiction}:

    \begin{itemize}
        \item LLM-Judge: $87.57\% \rightarrow 92.40\%$ ($+4.83$ pp)
        \item NLI Classifier: $81.15\% \rightarrow 83.07\%$ ($+1.92$ pp)
    \end{itemize}

    This finding has practical implications: \textbf{inter-model agreement can serve as a confidence calibration signal}. When both models predict the same label, particularly \textsc{Contradiction}, the prediction is more likely to be correct. This suggests that an ensemble of the two approaches could provide a more robust classification, using agreement as a quality filter.

    \subsubsection{Implications for Translation Quality Estimation}

    The NLI-based approach offers complementary insights to string-matching metrics:

    \begin{enumerate}
        \item \textbf{Semantic granularity}: Unlike binary metrics (e.g., Exact Match), NLI provides a three-way classification that distinguishes between complete semantic preservation (ENT), partial overlap (NEU), and semantic conflict (CON).
        
        \item \textbf{Robustness to paraphrasing}: Answers that are semantically equivalent but lexically different (e.g., ``the virus'' vs. ``COVID-19'') would receive low string-matching scores but high entailment probability.
        
        \item \textbf{LLM as a viable alternative}: The 69.77\% agreement with a dedicated NLI model, combined with calibrated probabilities via first-token extraction, indicates that generative LLMs can reasonably approximate task-specific NLI classifiers for answer comparison.
        
        \item \textbf{Ensemble potential}: The increased confidence on agreement suggests that a voting scheme or confidence-weighted combination could leverage the complementary strengths of both approaches for more reliable predictions.
    \end{enumerate}

    \subsubsection{Limitations}

    Several limitations should be noted:

    \begin{itemize}
        \item Both models were primarily trained on English data; performance on low-resource languages may be suboptimal.
        \item The LLM-as-Judge approach, despite the efficiency of first-token probability extraction, is still computationally more expensive than the dedicated NLI classifier due to the larger model size.
        \item The 30\% disagreement rate indicates non-trivial uncertainty in semantic classification, warranting further investigation into the nature of disagreements---particularly whether they correlate with specific error types or severity levels.
        \item The first-token probability method assumes that the label tokens are single tokens in the model's vocabulary, which may not hold for all LLMs or tokenizers.
    \end{itemize}
